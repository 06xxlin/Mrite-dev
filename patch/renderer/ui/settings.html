🧭 小白必看（环境配置）
1环境来源二选一：集成环境（Mrite_env）或系统环境。切换会丢弃另一模式的配置，需确认后生效。
2集成环境：软件自动找到电脑上的 Mrite_env 并加载其中的 Python 与 TinyTeX，开箱即用，找不到才回退内置 / 手动路径。
3系统环境：分别指定电脑里已装的系统 LaTeX（写作）与系统 Python（求解），并检测其必需库 / 宏包是否齐全——缺失可一键安装，或回退集成环境。
4想装更多库 / 宏包？打开软件同级目录 Mrite_env 下的「状态面板」（Python 库 / TeX 宏包）在里面装。

🧭 小白指引（务必先看，能少走很多弯路）
0如果你什么都不懂，直接用 DeepSeek 就好：端点已自动填好，只需在下方粘贴你的 API Key 就能用。
1想接哪个模型都行：官方直连、第三方中转、自建网关都可以填。中转/自建服务的地址格式常不标准（有的写 /v1，有的写 /anthropic），连不上先怀疑「端点」和「模型名」。
2模型名不能乱写：必须填服务商官方提供的模型 ID（在其官网文档里能查到准确名称）。乱写会直接报错「模型不存在」。
3API Key：在服务商控制台「API Keys」页面创建，以 sk- 开头。Key 属于敏感信息，别泄露给他人。
4全部填好后点「保存配置」，再回到任务页点「测试」，显示绿勾就说明配置成功了。

还没有 Key？点击 登录控制台 注册账号并创建 API Key，具体步骤请查看 API 文档
