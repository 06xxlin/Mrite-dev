# Mrite 开发版

> 数模论文 AI 自动生成桌面应用的**开发版**：免登录、免激活码、无会员时长校验，装上即用。

---

## 这是什么

Mrite 是一款面向**数学建模竞赛**的桌面应用：把题目和数据交给它，它会自动完成建模求解、
编程计算、绘制图表，最后产出一篇排版好的论文（含 LaTeX 源码与 PDF）。

这个仓库提供的是**开发版（免授权版）**：官方客户端的登录、激活码、会员时长校验全部移除，
任务直接使用你自己填写的模型 API Key，不经过官方服务器中转。适合个人学习研究、
二次开发与离线环境使用。

---

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 智能求解 | 读取题目与数据，自动拆解问题、建立模型、编写并运行 Python 代码 |
| 自动绘图 | 按求解过程生成论文级图表（分布图、热力图、组合面板图等） |
| 论文生成 | 自动撰写各章节并编译成 PDF，内置国赛/美赛等排版模板 |
| 工坊 | 内置写作、绘图、代码三个扩展工作台，可导入第三方扩展 |
| 历史与工作区 | 每次任务独立工作区，可随时继续、查看与导出 |
| 本地统计 | 本地记录用量与运行历史 |

## 安装

1. 到本仓库的 **Releases** 页面下载 `Mrite-Dev-<版本>-Setup.exe`
2. 双击安装：**无需管理员权限**，可以自己选择安装目录，可选创建桌面快捷方式
3. 安装完成后从桌面或开始菜单启动「Mrite 开发版」

> 安装包已经内置 Python、LaTeX(TinyTeX)、pandoc 等运行环境，装完即用，无需另外配置。

## 使用

1. 首次启动打开「**设置 → 模型配置**」，填入你自己的模型接口与 API Key
   （支持 Anthropic / OpenAI 两种格式的接口）
2. 回到「任务」面板，载入题目与数据文件
3. 点「运行」，等待它自动求解并生成论文

**示例配置**

| 项 | 值 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com/anthropic` |
| 模型 | `deepseek-v4-pro` |
| 格式 | `anthropic` |

## 常见问题

**需要登录账号或激活码吗？**
不需要。开发版已移除全部授权校验，界面会直接显示为已激活状态。

**会上传我的数据吗？**
不会。开发版不做运行记录上报，题目、数据与结果都留在本机；模型请求直接发往你自己配置的接口。

**用户数据放在哪里？**
`%APPDATA%\MriteUltra-2.6.13-dev`（设置、API Key、规则库、工作区）。
卸载时可以选择是否一并删除。

**可以安装到中文路径吗？**
建议装到**纯英文、不要太深**的目录。Python / LaTeX 在中文或过深路径下可能无法正常工作，
安装程序检测到这类路径时会给出提示。

**需要什么系统？**
Windows 10 / 11 64 位，安装后约占用 3.5GB 磁盘空间。

**想自己改代码？**
安装目录下的 `resources\app` 就是完整源码；开始菜单里的「开发模式（带 DevTools）」
可以直接以源码方式启动，改完重启即生效。开发与构建说明见 [BUILD.md](BUILD.md)。
